# RimTown 3D — 設計系統（Master）

> 2026-11-03 拍板：遊戲改為「AI agent 沙盒小鎮」。玩家是純觀察者（不在地圖上），唯一介入是批准／否決村民提案，另可和村民純聊天。畫面改為 three.js 低多邊形 3D；UI/UX 全部重新設計。此文件是全域規範，頁面層覆寫放 `pages/`。
> 來源：ui-ux-pro-max（style: Claymorphism／3D；color: Warm ink + amber accent on cream、Playful orange；typography: Noto Sans TC ＋ Soft Rounded；stack: threejs 指南），依本產品調整，不照抄參考截圖。

## 1. 產品定位
- 類型：瀏覽器觀察型模擬（AI agent 沙盒），桌機與 390px 手機。
- 使用情境：長時間掛著看、偶爾點進去看村民在做什麼、審一下提案。資訊要「一眼看得出誰在幹嘛」，不要塞滿。
- 風格關鍵字：柔和、玩具感、暖色、低多邊形、圓角、輕量毛玻璃卡片浮在 3D 地圖上。
- 不要：霓虹、深紫科技感、emoji 當圖示、全形標點露在英文介面。

## 2. 版面（桌機 ≥ 1024）
```
┌ 左上：城鎮卡 ────────┐  ┌ 上中：控制列 ─────────────┐              ┌ 右側：動態面板 320–380px ┐
│ 鎮名（大）             │  │ ⏸ 暫停 │ 1× 2× 5× │ 全景 │ 面板 │           │ 分頁：動態 │ 村民 │ 提案 │ 日報 │
│ 第 N 天 · 08:30 · 晴   │  └────────────────────────┘              │ 卡片列表（最新在上）        │
│ 人口 20 · 繁榮 42      │                                          │ …                         │
└──────────────────────┘                                          └──────────────────────────┘
          3D 地圖全螢幕（建築編號圓牌＋名稱；村民名牌；對話泡泡）
└ 左下：操作提示（拖曳平移 · 右鍵／雙指旋轉 · 滾輪縮放 · 點建築或村民看詳情） ┘
```
- 手機（≤ 768）：城鎮卡縮成一列頂欄（鎮名 · 第 N 天 · 時間 · 天氣）；控制列縮成兩顆（暫停／速度）；右側面板改成底部抽屜（三段：收起 56px／半開 45vh／全開 90vh），分頁橫向捲動；建築標籤只顯示編號圓牌，點了才展開名稱。
- 安全區：`env(safe-area-inset-*)`；地圖 canvas 永遠 100vw×100dvh，HUD 全部 `position:fixed` 浮在上面，不佔版面。

## 4. 字體
- 中文：`"Noto Sans TC"`；拉丁／數字：`"Nunito"`；回退 `system-ui, -apple-system, "PingFang TC", "Microsoft JhengHei", sans-serif`。
- 鎮名標題：Nunito 800 / Noto Sans TC 700，28px（手機 20px），字距 0.02em。
- 內文 15px / 1.55；次要 13px；最小 12px（只用於時間戳與編號）。
- 數字用 `font-variant-numeric: tabular-nums`。
- 字體由 Google Fonts 載入，`display=swap`；離線（PWA／WordPress）回退系統字，版面不可因此跳動（固定 line-height）。

## 5. 元件
- **HUD 卡**：圓角 16px；邊 1px `--border`；陰影 `0 6px 24px rgba(43,33,24,0.12)`；內距 12–16px。
- **按鈕**：高 40px（手機 44px）、圓角 12px；主色實心／次要為卡色＋邊；hover 150ms、active 縮 0.97；一律有文字，圖示用 SVG（Lucide 風格 20px），不用 emoji。
- **分頁列**：底線式；選中 `--primary` 2px 底線＋粗體。
- **建築圓牌（地圖上）**：28px 圓，`--card` 底、`--primary` 文字（編號 01–18）＋右側名稱膠囊（12px 圓角、13px 字）；距離遠時只留圓牌；hover／focus 放大 1.08。
- **村民名牌**：11px 膠囊，白底 85%，名字＋職業小字；被選中時主色底白字。
- **對話泡泡**：白底 92%，圓角 12px，左下小尾巴，最多兩行（超過加 …），8 秒淡出。
- **提案卡**：`L12` 編號膠囊 ＋ 標題（粗）＋ 狀態膠囊（進行中橘／投票中黃／通過綠／廢除紅／完成灰）；下方兩行摘要（可展開）；頁尾「提案者 · 第 N 天 HH:MM · 支持 x／反對 y」；鎮長操作列：批准／否決／擱置（三顆等寬）。
- **村民列**：頭像（3D 渲染的小圖或色塊首字）＋ 名字 ＋ 職業 ＋ 一句「正在…」＋ 心情色點；點了地圖聚焦到他。
- **動態列**：時間戳 ＋ 圖示 ＋ 一句話；對話類可展開看全文。
- **空狀態**：一句引導（「村民還沒提案，看看他們在聊什麼」）＋ 插圖留白，不要空白。

## 6. 互動與動效
- 動效預算：進場 200–300ms `cubic-bezier(.2,.8,.2,1)`；退場 120–180ms；列表新項目由上滑入＋淡入，stagger 40ms；`prefers-reduced-motion` 全關。
- 相機：左鍵／單指拖曳＝平移；右鍵／雙指拖曳＝旋轉（俯仰限制 25°–70°）；滾輪／捏合＝縮放（限制距離）；雙擊建築或村民＝聚焦（300ms 緩動）；`全景` 回到預設視角。
- 點擊優先序：村民 > 建築圓牌 > 地面建築區 > 空地（取消選取）。
- 鍵盤：Tab 可到所有 HUD 控制；地圖上 `F` 聚焦選中村民、`空白鍵` 暫停、`1/2/3` 速度、`Esc` 關閉面板。
- 觸控目標 ≥ 44×44；手機底部抽屜拖曳把手 ≥ 48px 高。
- 載入：3D 初始化時顯示卡色骨架與進度文字，不閃白。

## 7. 3D 場景規範（three.js r159，程序化幾何）
- 單一 `WebGLRenderer`（antialias、`setPixelRatio(min(dpr,2))`、`SRGBColorSpace`、`ACESFilmic`）；手機低畫質：dpr 1、關陰影、樹減半。
- 光：`HemisphereLight`（天 `#dfefff` / 地 `#b8a37a`）＋ `DirectionalLight` 日光帶 2048 陰影圖（桌機）；日夜由遊戲時間插值：正午 `#fff4e0` 強 1.1 → 黃昏 `#ffb070` → 夜 `#6c7fc7` 強 0.25；夜間窗戶 emissive `#ffd27a`、路燈點光（上限 8 盞）。
- 地形：每格 1 單位；草 `#7cc26b`／`#86cb74`／`#72b863`、土路 `#c9a470`、石板 `#a39784`、水 `#4fb3e6`（低 0.25 單位、透明 0.85、緩慢波動）、沙 `#e8d7a8`、雪 `#f2f5f7`、碎石 `#9c9388`。
- 樹：圓錐×2 疊（`#4f9a4a`／`#5faa58`）＋圓柱幹 `#7a5230`，InstancedMesh；秋季葉色偏 `#d9924a`。
- 建築：牆 `#f1e4cf`（依地點色相微調）、屋頂依類型（酒館 `#c25a4a`、商店 `#d99a3c`、診所 `#5aa8c7`、禮拜堂 `#8a6fb5`、工坊 `#8c7055`、住宅 `#c9644f`／`#d08458`／`#b5685a` 交替）；門 `#7a4e2e`、窗 `#cfe8f5`（夜 emissive）；四坡／雙坡屋頂、煙囪；陰影接地用柔和圓形 decal。
- 村民：方塊小人（頭 0.5、身 0.45×0.55、短腿），膚／髮／上衣／配件沿用 `LOOK_*` 色表；走路＝腿擺＋輕微上下；睡覺＝躺倒透明 0；表情用 sprite（SVG 圖示，非 emoji）。
- 標籤：HTML 覆蓋層（投影座標），不用 CSS2DRenderer 模組；每幀只更新可見者；超過 60 個標籤時依距離裁切。
- 霧：`FogExp2(skyColor, 0.012)` 做遠景收斂；相機 far 300。
- 效能目標：桌機 60fps、手機 30fps（30 村民、40 建築、400 樹）；draw call < 150。

## 8. 文案與雙語
- 介面繁中為主；英文模式所有標籤走 `t()`，標點半形（沿用 `cjk-punct-audit`）。
- 提案文案：規則式模板（有 AI 時 AI 潤稿），口吻像村民自己說話，不用公文腔。
- 數字與單位之間留半形空格（繁中亦同）：`第 12 天`、`150 銀幣`。

## 9. 無障礙
- 文字對比 ≥ 4.5:1（已驗：`--fg`/`--bg` 12.6:1、`--muted-fg`/`--bg` 5.2:1、白字/`--primary` 4.6:1）。
- 所有圖示按鈕有 `aria-label`；提案狀態變化用一個 `role="status" aria-atomic="true"` 區塊播報「L12 已通過」。
- 鍵盤可達、focus 可見；3D canvas 本身 `aria-hidden`，資訊由 HUD 提供。
