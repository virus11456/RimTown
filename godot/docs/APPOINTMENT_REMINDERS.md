# 赴約提醒與常駐入口

底部新增「約定」入口，可直接回到目前邀約、待改約或已接受的約定頁；沒有有效約定時停用。手機導覽列縮小按鈕間距，五個入口仍保持兩字標籤與觸控高度。

已接受的約定，在開始前兩個遊戲小時內、開始時，以及開始後實際觀察到對方在約定場所時，各提供一次狀態列提醒。跳過前階段直接進入較後階段時，不補播舊提醒；同一階段不反覆蓋掉其他訊息。未接受、過期、取消、居民過世或場所移除不發赴約提醒。對方僅設定目的地不算到場。

提醒不開彈窗、不自動行走、不花資源或呼叫 API。忙於聊天、事件回覆或檔案對話框時延後，不提前消耗提醒。純模擬不主動產生 UI 提醒；介面呼叫 helper 並保存外部 book。已提醒狀態以一個約定識別與最高階段保存於 `_godot4a.appointment_reminder`，不混入 quest_balance；原生重載不重播，同 NPC 改約的新時間可重新提醒。

狀態列可能被其他重要訊息替換；底部約定入口持續可用。這不是作業系統通知或遊戲關閉後的提醒。
