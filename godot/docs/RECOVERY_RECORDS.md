# 恢復結果與居民回憶

2026-09-13。

恢復安排結束時保存最近八筆結果，区分達到恢復目標、短暫恢復時間用完、以及必要行程／逾時等中止。只有正常更新已實際執行、且人在自己家中停步的用餐或睡眠，才記錄其時間。進行中的計畫本身不證明行為發生；舊存檔沒有的觀察資料不補造。

行程頁顯示原因與在家用餐、休息分鐘數（遊戲時間），同時寫入居民記憶。結果只寫一次，已結束的存檔再載入不重算，也不增加物資、照護效果或服務額度。

既有本機近身主動搭話入口可在結果一天至七天內提起最近一筆恢復事件，保留見面約定回憶的優先順序及原本全鎮每日兩次、同居民每日一次限制。用餐／休息台詞只在有對應紀錄時出現；未到家就中止時不聲稱吃過或睡過。回憶帶有事件來源，讀檔後不重複。這是可驗證事件的本機台詞，不代表已測試連線模型自主推理。

160 項控制檢查涵蓋實際返家恢復、結果與記憶去重、讀檔、紀錄上限、逾時與中止分類，以及真實近身搭話入口、聊天限制和回憶來源。另跑 16 組相關回歸，涵蓋照護、恢復、搭話、約定回憶、睡眠及守衛。

海風鎮原始四日自然模擬共 184,320 個移動影格，八筆恢復結果中六筆達成目標、兩筆在已用餐／休息後因必要行程中止；沒有自然照護完成，不將自我恢復混算成醫護／牧師服務。
