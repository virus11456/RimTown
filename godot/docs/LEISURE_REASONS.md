# 休閒未完成原因與觀察依據

行程現在保存是否曾在指定時段實際觀察到居民抵達，以及停留時曾發生的三種中斷：急迫進食／休息需求、離開場所、位置觀察缺口。中斷種類去重，不按畫面幀無限增加紀錄；結算後隨最近七筆歷史保存。

期限結束或跨日關閉舊行程時，依紀錄分辨：沒有足夠的到場觀察、觀察期間未確認到場、已確認到場但未完成連續停留。已觀察的中斷也會附在結果中。這些是事件紀錄，不表示某次中斷必然是失敗的唯一原因，也不把未到場推論成卡住路徑。

行程頁沿用結果欄與最近結果列表，會顯示新原因；本機「詢問休閒安排」對未完成者補上同一原因。AI 提示原有的 reason 欄也取得該內容。舊歷史不補造觀察；新欄位缺省仍相容。沒有增加行程次數、物資、銀幣或完成回饋，也沒有改移動和排程條件。
