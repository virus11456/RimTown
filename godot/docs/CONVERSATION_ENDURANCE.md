# 主動聊天、日常作息與赴約八日整合包

聊天失效後現在會指出變更類別：玩家約定、班表／上工、休閒紀錄，或居民同行／活動與需求。自由交談可直接「查看目前行程」，從行程頁「回到自由交談」後保留原草稿；查看資料不發送 API、不改變好感或行程。等待回覆時也能查看，返回後仍保持原請求。

## 八日連續整合

邊境鎮、海風鎮各推進 768 tick，每 tick 完整 480 移動幀，共 737,280 幀。沿用原始居民、職業、資源、地圖與補給設定。旅人正常提案，鎮長每日審核後才能按原價執行灌溉工程；角色自行走路、進門、上工與返家睡眠。玩家由測試控制器使用正常碰撞移動走到會場。

每六個 tick 發起一次聊天，模擬 AI 等待一個 tick 才回覆，期間世界照常前進。每十二個 tick 優先處理實際排入的事件評論或真心話，沒有強制增加好感來觸發里程碑。模擬回覆明確提議見面，邀約仍由原規則選空檔，控制器逐份點擊接受；不是口頭聊天直接算碰面。

一個 tick 是遊戲內十五分鐘，1× 約八秒。本測試固定取樣時段、固定模擬回覆，失效比例只是這個壓力情境的結果，不能解讀成正式服務錯誤率。失效後的手動重送在同一遊戲時刻立即返回，用來驗證操作路徑；不代表真人或正式 API 沒有等待。沒有自動重試，也沒有呼叫正式 AI。

主動事件失效時用原事件本機台詞；自由回覆失效時先用完整快照確認沒有套用任何效果，再透過實際按鈕查看行程、返回、手動重送。正常回覆必須仍能送達。

各城在模擬中讀檔三次，保留實際位置。另有受控交錯回覆測試：讀檔後啟動新請求，再讓舊請求返回，舊請求不能解除新的等待狀態或清除新草稿；背景與自由聊天同時等待時，舊背景邀約不能覆蓋後來的自由聊天約定。

## 結果與存檔

整包 1,392 項檢查通過。兩城各完成 7 次見面，共 14 次；35 位原始居民全部曾在自家睡眠，沒有阻擋格、瞬移、異地睡眠或負庫存樣本。邊境鎮 tick 264、海風鎮 tick 360 完成灌溉，兩城都在 tick 72 經核准扣除木材 10、石材 15、工具 2。

| 模擬情境 | 邊境鎮 | 海風鎮 |
| --- | ---: | ---: |
| 原始請求 | 128 | 128 |
| 事實未變，接受回覆 | 79 | 89 |
| 事實變更，原回覆失效 | 49 | 39 |
| 手動重試成功 | 48 | 38 |
| 背景失效改用本機台詞 | 1 | 1 |
| 含手動重試的模擬請求總數 | 176 | 166 |

每城包含 124 次自由交談、1 次真實工程事件評論及 3 次自然好感里程碑真心話；每次原始請求都完成處理。

詳細結果見 CONVERSATION_ENDURANCE_FRONTIER.json、CONVERSATION_ENDURANCE_HARBOR.json、CHAT_REQUEST_OVERLAP_TESTS.json、CHAT_SCHEDULE_NAVIGATION_TESTS.json、CONVERSATION_DELIVERY_TESTS.json 及整包回歸報告。

自然測試的 physical_meetings 計數只記錄移動幀中 waiting→met 的轉換；後續已站在會場的玩家，可能在 tick 處理內直接完成碰面，不會進入該計數。完整碰面次數以交付驗證 verified_meetings 及存檔的約定歷史為準。samples.changes 比較到回覆／重試套用之後，可能包含新邀約效果；判斷等待期間是否失效應看套用前取得的 stale 欄位。

交付存檔關閉背景事件與真心話的連線開關，保留已推進世界、位置、付費建設和真實赴約歷史；仍可手動使用自由聊天。兩份存檔經選檔器重新匯入驗證。不將模擬台詞稱作正式 AI 品質驗收，也不宣稱所有任務與結局已完成。

本包為本機 Godot 開發，未推送 GitHub／Vercel。下一個整包接續不同職業居民的邀約與任務在自然作息中的整合，特別保留單守衛／日夜輪班及公共資源權限；網站整體風格檢視仍在既有後續排程。
