# 修正返家卡牆，沿路慢慢走回房間

兩日逐 tick 追蹤發現，楊鋒一直停在 (504, 280)、黃莉一直停在 (616, 280)。北區兩棟住宅和鎮公所的原始配置重疊，鎮公所覆蓋了住宅門口的可行走格，導致兩人從開局就無法移動；精神耗盡後仍卡在同一處。這不是單純睡眠排程不夠長。

3D 地圖現在遇到鎮公所與住宅重疊時，將鎮公所整組建築、門口與標籤移至最近可容納的安全空地，避開既有建築、自然場所、工地、裝飾和道路。住宅地址、角色座標、模擬工作場所 ID 與公共資源不變。邊境鎮的鎮公所新位置為格座標 (49, 3)，建築選址也保留同一處占地。純來源布局重播仍沿用原布局。

居民維持每 frame 0.3 像素的一般步行速度，按道路與門口走進房間；不使用睡眠瞬移或加速返回。只有真正到自己的住處、停止行走且完成門口過渡，才恢復精神。使用者再次要求的「睡覺回房間不要飛回去」已列為持續驗收條件。

舊版存檔的路線可能指向舊鎮公所；首次讀取時保留角色座標，清除舊路線目標，於下一 frame 重算路徑。新的存檔保存配置版本，正常讀檔完整保留行走狀態。兩個原本卡牆的座標在修正地圖後可行走，無需搬動居民。
