# 上班前就地用餐（2026-09-11）

## 問題與修正

原始兩日軌跡中，高朗已經到廣場，卻因飢餓折返酒館，導致 18:00 接班仍在路上。其他四位居民第二天上工前也因用餐往返延誤。

3D 居民在班次前四小時內，如果飢餓可能在上班前降至緊急門檻，會在已實際到達並停下的自己房間、工作地點或酒館先用餐。使用每 tick 最多下降 2 的保守估計，觸發門檻最高 35；不要求吃到全滿。用餐仍使用既有每 tick +20 飢餓恢復，沿用原本每日公共伙食規則，不新增資源交易或個人錢包。

沒有走到上述位置、正在走路或進出門時，不適用這個提前用餐規則。玩家、死亡、避難、極低體力、睡眠時段、缺失工作設施與非上班前時段也不適用。吃完即恢復原本通勤判斷；角色速度、班次和睡眠窗口不變。
