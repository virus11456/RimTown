# 受阻位置診斷與恢復

2026-09-11，本包處理角色實際座標位於不可通行格或地圖之外的情況。居民資料與今日作息行程會顯示「目前位置不可通行，暫停移動；地圖障礙解除後才能重新找路」，並保留預定活動。原因依當下地圖查詢，不把存檔中的舊旗標當成事實。

3D 自動行走遇到這種位置會停止踏步並保持座標。當該格重新可通行時，清除舊尋路快取，重新規劃路徑，沿用原本步速與門口流程。讀檔亦保留實際位置；死亡狀態優先於移動提示。

這不是任意脫困或拆除功能。障礙仍存在時不能保證恢復，也沒有把居民送到旁邊空地。合法起點但整條路被封住、沿牆踏步及無路可走的細分原因留待下一包；不把這些狀況全部宣稱已修好。

驗證使用受控障礙格：連續 600 幀沒有位移或行走動畫；清除障礙並刻意污染舊快取後，角色重新找路且實際走到目的地，最大單幀位移 0.804 像素以下（包含原有不足一像素的路點收尾）。原始步速不變。另驗證 JSON 座標還原、過期旗標、手動旅人原因查詢，以及 375px 真實居民卡片與行程頁、原生讀檔不挪動角色。

證據：`BLOCKED_POSITION_TESTS.json`、`BLOCKED_POSITION_UI_TESTS.json`。測試中移除障礙與還原位置僅為測試設置，不是玩家可按的救援操作。未呼叫正式 AI，也未新增資源、產量或個人錢包。

本包回歸共 151 項通過，涵蓋受阻核心／介面、既有行走、行程、工廠占位、兩日作息與輪班讀檔。兩日作息回歸使用舊測試的每 tick 120 幀，不是完整 1× 八日耐久；詳見 BLOCKED_POSITION_REGRESSION.json。
