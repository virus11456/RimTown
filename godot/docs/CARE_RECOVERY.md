# 求助暫緩後的返家恢復

2026-09-13。

## 行為

出發前判斷若因居民飲食／體力不足而暫緩，會再檢查返家路程與空檔。可安全完成返家與最多一小時恢復，且不擠到工作、睡眠與約定，才建立一次有固定期限的安排。仍須保留回程中的飢餓與體力餘裕；沒有安全路線或空檔時維持原有必要生活行程，不強迫出發。

居民依原有步速穿過門口回到自己房間。尚未到家或還在走動時，活動是返家，不會因這份安排補充體力或飢餓值。實際到家停步後，依出發前不足的飲食／體力目標選擇用餐或短暫睡眠，沿用既有用餐與睡眠恢復速度。達到目標或最多四刻（一個遊戲小時）即結束。

每人每日最多建立一次返家恢復安排，返家預留最多四個遊戲小時，期限不反覆延長。上工、睡眠班表、通勤、赴約、玩家服务、搬家、逾時或關閉社交等必要變化會結束安排。恢復完成後清除舊暫緩提示，下一刻重新評估是否還需要照護；若已不疲憊或低落，直接回到生活，不為了使用服務而再去求助。

此安排不消耗每日求助次數，不給照護完成效果、服務額度或職業獎勵，也不產出物資。實際飢餓／體力變化沿用既有 SimNeeds 用餐與睡眠規則。

## 驗證

控制案例涵蓋兩鎮醫護／牧師、返家途中不恢復、穿門到家才用餐與睡眠、實際存檔重載、恢復後結束、每日上限與固定期限。另驗證實際求助前檢查自動建立恢復安排，以及上工、約定、關閉社交、搬家與逾時中止，取消本身不改需求數值。

原生畫面記錄控制情境下的返家、在家用餐與在家短睡。這些是控制驗證，不等同原始城鎮自然發生。
