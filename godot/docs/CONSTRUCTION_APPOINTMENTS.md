# 施工改道與約定期限

2026-09-11，本包驗證既有工廠刷新與行走的整合，並修正邀約到期判斷的先後次序。

## 已修正

已接受／正在等待的約定到了結束 tick，先以未碰面結案，不能因同一刻發現班表或返家路程不適用而再提出新改期。直接呼叫 NPC 改期提議也會拒絕到期的約定。結案保留「對方已到、玩家未到或未靠近」與「對方尚未抵達」的區別，記憶與歷史只記一次。

期限內發現衝突仍可提出改期，原 due／until 不會直接改寫，玩家明確接受後才換成新時間。期限前已提出、正在等玩家回覆的改期，仍按原本的提議回覆期限處理。本包沒有自動延長等待、提高步速或瞬移。

## 整合驗收

- 使用受控鎮長／材料與居民起點，找出原本穿過未建工廠預留地、通往現有酒館門口的實際路徑。按真正建廠按鈕後，只扣原價木 20／石 15／銀 80，刷新立刻改道，沒有挪動角色。
- 匯出／載入原生進度後，居民仍繞開工廠，經過 approaching／entering 階段走入酒館，再按原速走回自己住宅。所有取樣點可通行，最大單幀位移低於 1 像素。此案例固定時鐘，隔離行走與幾何，不是自然邀約準時完成的證據。
- 新增實際返家門口受阻案例：路程估算變成不可達，約定恰好到期時不改期、不完成、不改座標；後來解除障礙並放置雙方於現場，也不會補算見面或重發記憶。放置角色和封門僅為測試設置，並非新增玩法。
- 核對到期前仍可明確同意改期，以及 JSON 讀檔不能讓已結案約定復活。
