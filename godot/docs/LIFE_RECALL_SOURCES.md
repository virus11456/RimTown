# 生活回憶來源查看

居民對話中，見面約定、玩家照護／談心服務、居民自行赴診、返家恢復與休閒回憶新增「查看這段生活回憶紀錄」。與既有職涯交流來源並行；可查看目前行程，或返回原對話繼續未送出的草稿。

依居民、結果、刻數及各類來源欄位比對保存的原始紀錄。找不到、內容不符或同時匹配多筆時顯示無法核對，不依聊天副本補造。一般自由文字與未附回憶來源的服務邀請不提供此入口。來源保存有筆數上限；已超過主動搭話期限但原始紀錄仍存在時，仍能查閱。

完成、未完成、中止與恢復時間用完分開呈現。約定頁標示原約定時間，休閒頁標示行程日期，均不冒充實際完成時間；沒有保存的完成日期不推算。恢復用餐／休息顯示實際在家的遊戲分鐘數，不推定已康復。居民赴診只顯示原回憶引用且與原始追蹤一致的到家／上工觀察，不把移動或進食意圖當完成，也不追加事後才發生的里程碑。

閱讀不改進度、不呼叫 AI、不重試服務或發放效果。世界更新不換掉來源頁；聊天等待回覆時入口停用。
