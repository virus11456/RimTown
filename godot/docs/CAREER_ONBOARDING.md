# 值勤上手與下一步提示

每項可做工作旁新增「下一步」，在按開始前呈現目前阻礙：今日三次完成額度已用完、材料／交易用途尚未核准、公共材料不足、尚未到操作位置，或目前已到位。提示使用現有核准與到場檢查，按開始時仍會重新核對需求與條件。

## 操作流程

1. 從職業與值勤頁登記想做的職業，或先打開職業指南了解玩法。
2. 在實際工作旁閱讀下一步；公共生產與交易先取得相應核准。
3. 有操作台的工作可按「走到操作台」，旅人沿路正常步行，你可隨時用方向鍵接手。
4. 到位後再按開始。抵達本身不開工、不扣料、不發獎勵。
5. 停留至值勤完成；畫面會顯示完成結果，職涯只計入一次。離開現場、需求失效或跨日會依既有規則取消。

所有職業仍共用每日完成額度；成果歸小鎮，產出仍受需求、備貨及核准限制。本包沒有新增資源、錢包、職業獎勵或自動開工。

測試的初始工作需求、核准及門口位置為受控情境，後續走路、開始、途中存讀檔與結算走實際遊戲流程，不視為自然發生的任務完成率。

驗證：77 項上手專項與 8 組整合合計 2743 項通過。包含兩鎮可用操作台職業、現場移動、開始、途中讀檔、完成、材料不足、交易核准、手動接管、停止、需求改變及每日額度。大量移動檢查逐影格計數，不等同獨立功能數。
