# 照護接待與準備時段

2026-09-13

## 問題與改動

原有可行性判斷先檢查飲食／體力，再檢查服務者下班及必要行程。當兩者同時不符時，會把已無接待空檔的情況標成需要恢復，甚至啟動返家準備。

現在先核對直接赴診的接待、工作、睡眠、約定及照護後返家時段。時段可行且需要恢復時，再核對整段準備：實際返家路程、最多一小時恢復與釋放安排的一刻、從自家停留點赴診、到場半小時照護及後續返家。也核對服務者在整段等待後的飲食／體力餘裕。

從家出發的路程用於新的恢復目標，避免沿用居民原本在街上或診所旁的距離。所有估算不移動居民、不預支恢復效果。時段不足不啟動恢復、不扣每日機會；之後可重新評估。已開始的舊恢復安排仍沿用原期限。

這是保守的出發前估算，預留完整恢復上限，並不保證服務者未來一定留在原地。正式出發仍重新檢查，原有中止、每日一次求助與每位服務者每日三次限量不變。未延長醫護班表、縮短步行、增加資源或把自行用餐休息算成照護。

## 驗證

兩鎮醫護／牧師共 64 項專項檢查通過：同時飢餓與臨近下班、直接可赴診但返家準備來不及、從家重新計算路程、服務者需求、既有約定、四小時赴診上限、不消耗機會、晚些時候重新準備、實際讀檔及到家用餐。

相關回歸與兩鎮七日自然結果見本包 JSON 報告。交付的四日進度沿用既有存檔，另做匯入驗證；七日測試沒有另產出交付進度。

18 組相關回歸通過，包含新增 64 項專項、原有 537 項日常循環、照護中止／額度／候補／恢復／讀檔，以及 22 項交付進度匯入。

兩鎮各七日自然模擬通過，共 645,120 個移動影格；原有 35 位居民皆實際步行並在自己家睡眠，守衛班表、步長、腳底高度、讀檔與每日額度檢查通過。海風鎮保留的 26 筆居民／日暫緩皆為「抵達並完成前，服務者就要下班」；沒有啟動赴診準備用的返家恢復，兩鎮也沒有自然照護完成。這不是照護平衡完成，而是移除時間已不可行時的準備安排。

下一步需整體處理下工後需求、接待空檔與正常睡眠的配合，不藉由放寬每日限額、強制居民赴診或增加免費恢復達成測試數字。
