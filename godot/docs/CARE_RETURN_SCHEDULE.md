# 照護往返與既有約定

長途赴診必須保留去程、三十分鐘照護與步行返家所需的空檔。原本的檢查已保護上工、睡眠，以及照護結束前的約定；本包補上居民返程與已確認見面／自主休閒出發時間的衝突檢查。

例如照護本身能在下一個約定的準備時段前完成，但居民仍需走一段長路回家，這次求助會先暫緩，接待頁顯示「照護後步行返家會與已確認的約定或休閒安排重疊」。拒絕不消耗每日求助機會或接待額度，也不取消原約定。原約定取消後會重新評估。

檢查共用原本的實際接待點到住家路線、角色步速、所選遊戲節奏與約定準備時段。直接赴診與返家準備後再赴診都經過相同的行程檢查。照護者只需在服務結束前保留時間，不因受照護居民的返程延長留守。既有已出發的行程仍按原期限處理，不延長舊約定。

本包沒有改動地圖、班表、步行速度、睡眠或照護限量；也不以強迫求助增加完成數。它修正完整往返排程的缺口，並不代表原有節奏下所有長途赴診都已可行。

## 驗證方式

72 項專項涵蓋兩鎮、醫護／牧師、原有／從容節奏，驗證只撞到返程的已接受約定、休閒準備、存讀檔、取消後釋放、照護者準時釋放，以及接待頁顯示相同原因。此為受控行程測試；介面使用無視窗真實場景驗證文字，沒有新增原生截圖。

自然模擬使用原有節奏、兩鎮各兩日，保持原始居民需求、職業與位置，逐影格核對正常步行、到家睡眠、守衛值勤、照護額度及中途讀檔。完整結果見 CARE_RETURN_REGRESSION.json。

驗證結果：11 組檢查合計 472 項通過；其中兩鎮各 192 刻、92,160 個移動影格，邊境鎮 20 位、海風鎮 15 位原有居民均觀察到步行及到家睡眠，無非法步移、接地、守衛值勤或照護額度錯誤。兩鎮本次皆無自然照護完成；海風鎮仍有趕不上下班、睡眠或返家的暫緩，不能視為長途接待成功率已改善。
