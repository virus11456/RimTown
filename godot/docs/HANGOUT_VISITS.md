# 居民同行共同到場

3D 居民同行安排現在分別記錄兩人出發，只有雙方已出發、實際位於同一目的地且距離不超過 48 像素，才結算碰面並各留一筆事實記憶。設定相同目的地不等於到場。重複觀察或讀取已完成進度不重複結算，不額外增加物資、銀幣或好感。

出發期限沿用提出後四小時；共同到場期限為該期限再加兩小時。工作、需求、避難、既有玩家約定或離開目的地會中止同行，逾期沒有近距離碰面則記錄未完成。行程頁沿用最近同行狀態顯示原因。同行中不另外產生重疊同行提議；移動使用穩定目的地並停用卡住瞬移補救。

紀錄隨世界保存，新增時優先清除舊終止紀錄至 20 筆；仍進行中的安排保留。3D 載入若缺少任一同行者座標，取消尚未確認的安排，避免重建位置直接變成成功。純世界未啟用同行保護時保持原行為。

驗證共 129 項：本包 24，優先順序 20、介面 6、社交產生安排 4、實際位置社交 8、自由交談介面與重播 33、移動回歸 34。新測試包含受控起點的兩人真實 SimMotion 步行、單方到場拒絕、雙方碰面、不重複記憶、缺位置重載及中止原因。沒有呼叫正式 AI，也不是自然好感成長後完整同行生活週期驗收。

仍沿用原有目的地停留與作息選擇；途中可能轉往其他事情而失敗。本包不強制延長等待、不自動重新協調，也不以普通生成台詞建立約定。下一包處理同行等待與中斷後的協調，再做原始居民自然行程驗收。
