# 居民提起自己的休閒經歷

日常主動搭話在沒有可用的見面回憶時，可引用同居民最新一筆休閒完成、未完成或取消結果。結算至少一個遊戲小時後、兩日內才可提起；同結果一次。未知結算時間的舊紀錄、不支援的狀態及自由文字不作依據。不往更舊紀錄挖掘已略過的結果。

完成者只說自己去休閒，不聲稱玩家同行；未完成者沿用實際記錄的原因；取消者不猜測責任。這是本機台詞與結果引用，不是生成式反思。既有近距離、同場所、空閒工時、需求、每日全鎮兩次、同居民一次及四小時間隔均保留。見面回憶優先。沒有額外好感、技能、銀幣或商品回饋。

聊天的 `_godotRecall` 以 kind=leisure 區分來源，去重 token 使用獨立前綴，沿用日常搭話紀錄與存檔。原聊天頁即可看見台詞，不強迫開新視窗。
