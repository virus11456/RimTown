# NPC 同行邀約與慢走返家

3D NPC 邀約地點篩選現在同時檢查雙方的回家路程：從見面處經出口、各自住家門口到室內，按一般步行速度估算，回程每 tick 預算 30 像素加緩衝，不採赴約時的較快速度。回程若跨入睡眠、通勤或工作時段，或沒有有效住家／路徑，就不提出該地點；正常聊天仍會繼續。

原有出發延遲、前往見面處與緩衝之後，才開始計算回程。這是依當時路線和班表的可行性估算；途中臨時需求、延誤與班表變動仍可能使人晚歸，不保證到家時間。

雙方經實際位置觀察確認碰面後，會建立一次有期限的返家行程，接到現有正常慢走路線。途中保留住家目的地；到家、住址不符或期限結束時清除。工作、通勤、緊急需求、避難及已確認且正在引導的玩家約定仍優先，不藉返家增加資源、精神或瞬移。回到家不等於立即睡覺，仍遵守既有睡眠／疲憊規則。

## 驗證

166 項檢查通過：回程可行性與實際步行 13、社交邀約生成 6、碰面後回程 12、原可行性 8、邀約建立 4、目的地存在性 6、同行碰面 22、等待介面 5、玩家赴約介面 13、手機作息 13、自由聊天／重播 33、睡眠中斷 11、提早返家 20。

受控夜貓子兩人位於同一公園：23:15 原本僅看去程時可提出邀約，加入回程後拒絕；12:00 則保留同一地點。測試分別讓兩人沿真實路線慢慢走回各自住家，均在估計回程預算內抵達，最大逐 frame 位移小於 1 像素。另驗證睡眠邊界、工作衝突、缺少路徑／住家／位置，以及估算不修改資源或角色座標。

社交生成測試明確提高好感、固定時鐘並限制一個地點，分別嘗試 80 次，確認提議真正經過新篩選，晚間不提議時仍保有聊天。碰面回程測試使用受控雙方實際同地近距離觀察，再透過世界更新、慢速移動與存檔恢復，驗證返家目的地、到家／逾時清理及工作／飢餓優先。

本包未重跑自然 32 日同行或兩日睡眠統計，不把受控成功當作自然邀約頻率提升；既有 32 日成功數據屬早期版本。玩家邀約卡的候選時間、接受與改期流程尚未套用這次回程檢查，下一包接續處理。也沒有呼叫正式 AI 服務。
