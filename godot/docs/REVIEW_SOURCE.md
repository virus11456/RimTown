# 職涯回憶來源查看

居民對話中，帶有職涯交流回憶的訊息新增「查看這段職涯交流紀錄」。來源頁核對原始交流帳本的對象、職業、階段、完成刻數與選項，再呈現當時對象姓名、遊戲時間及原回覆。歷史內容不代表旅人目前職務或居民目前位置。

來源缺失、不一致或資料不完整時，明確說明無法核對，不只依賴對話中附帶的副本。舊紀錄沒保存完整時間時不補造。對話超過主動回憶的兩日窗口後，原始交流仍存在就能查閱，不重新觸發回饋。

閱讀不修改進度、不呼叫 AI、不領獎、不轉職。來源頁保留對話草稿，返回原對話可繼續輸入；有回覆進行中時來源按鈕不可點，閱讀期間世界更新不換頁，也不插入新主動搭話。

## 驗證

14 項來源專項：已完成原紀錄、只讀、錯誤對象、階段／時間／選項不符、超過回憶窗口、舊時間缺失、讀檔、缺失帳本及異常副本。

76 項真實手機介面流程檢查涵蓋兩種職涯交流、實際搭話、來源按鈕、核對回覆／選項、捲動控制項寬度、世界更新保留來源頁、返回與草稿、讀檔去重。初始角色與相遇位置為受控條件。

8 組整合共 292 項通過，包含玩家聊天、日常搭話、職涯交流與值勤追溯。未新增原生截圖，既有原生畫面待辦保留；本包介面驗證為無視窗真實控制項測試。

## 使用

收到職涯回憶搭話後，在居民頁點「最近搭話」，再點該訊息下面的來源按鈕。可返回原對話，也可另看該職業目前進度。
