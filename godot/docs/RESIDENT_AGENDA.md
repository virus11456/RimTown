# 居民作息、目的地與實際足跡

居民資料新增「今日作息與行程」：以現行 jobKey 工時、工作場所與早起／夜貓性格顯示平常作息，並提醒需求、睡眠與避難會調整活動。既有約定顯示接受／等待／取消原因；未接受及 NPC 改約待確認會明示尚未排程／原約暫停。玩家本人的頁面不杜撰自動作息。

頁面與居民摘要以 SimMotion 真實位置計算目前場所，另列模擬的目的地。角色尚未抵達或仍在場所內移動，會顯示「預定工作／休息」而不直接聲稱已在工作或睡覺；不同住家即使位於同一住宅區，也不算抵達自己目的地。

匯入 dailyPlan.blocks 的自由文字單獨列在「文字備忘（未排入行程）」，不視作執行引擎的安排。這些舊欄位目前未驅動行動，頁面不再藉文字行程暗示角色會照做。本包不新增自由文字或 AI 生成行程執行器。

## 實際足跡

每個 app 模擬 tick（遊戲十五分鐘）對當時實際位置、目的地與移動／活動狀態取樣；相同狀態去重，每人每日最多 160 筆，換日清空。此為取樣，不是逐 frame 全路徑錄影。關閉既有足跡設定會停止新增。

新的 PhysicalTrace 與畫面位置同屬視圖狀態，保存於 _godot4a.physical_trace，包含去重狀態。純 SimWorld 不擁有真實位置，因此維持原作息／文字記錄及來源相容性；UI 把它們標成「作息／文字紀錄（未核對實際位置）」，不冒充新實際足跡。舊資料保留，但畫面只列最近二十筆文字紀錄。切換小鎮會載入各自資料，不沿用前一鎮足跡。

## 驗證與試玩

AGENDA_TESTS.json：受控實際位置與目標、同區不同住家、未執行文字不能成為實際足跡、工時／睡眠時段、去重／重載／換日／上限／停用，以及觀察不改動純模擬。

AGENDA_UI_TESTS.json：居民入口、作息及足跡頁、正常 app tick 刷新、未接受約定、明示的虛構文字備忘、375px 排版、壓縮存檔原生重載與換鎮隔離。原始 JS 足跡對照、進度壓縮載入及聊天介面回歸通過。

outputs/居民作息與實際足跡.rimtown 含一段刻意未執行的文字計畫供區別驗證。載入後選「居民 → 陳偉 → 今日作息與行程／今日足跡」查看。這是受控驗收場景，不表示測試中的遠行已成為遊戲玩法。

仍待：可驗證的生成行程、行程反思與重排、自由文字轉正式安排；不可將本包宣稱為完整 AI 自主規劃。
