# 缺少位置資料時的停留重載

載入 3D 專案存檔時，先檢查每位居民是否有保存的 motion 位置。若行程尚未結算而該居民沒有保存位置，清除舊 observed_tick 與 dwell，改為待觀察；如果當時正在停留，記錄一次觀察缺口。過去已確認到場的事實與既有歷史不抹除，已完成／取消等結算不更動。

完整位置的正常存檔保持已取得的連續停留進度。缺少全部 motion 或只有部分居民位置時，不能將載入後重建的位置拿來承接舊停留進度。仍須重新取得正常觀察才能完成，沒有補發需求回饋或任何物資／銀幣。行程頁原因會說明位置缺失、需重新觀察。

本包針對位置資料缺失，不是所有畸形存檔欄位的全面修復，也不改純 SimWorld snapshot 的重載語意；由 3D app 在還原視圖位置時檢查。
