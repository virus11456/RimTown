# 自由交談的行程資料時效

自由交談送出前保存提示使用的休閒資料與目前見面約定，收到 AI 回覆時再檢查。如果資料改變，整份回覆不套用：不新增對話／記憶、不改好感與戀慕、不套用附加交談意圖、不增加聊天任務進度、不提出新邀約。原本由模擬或玩家操作造成的變化保留。

介面提示「等待回覆期間，行程或見面約定已改變」，保留草稿並解除等待狀態，讓玩家自行重新傳送；不自動重試或另外呼叫 API。原請求已送出，這項保護不會退還服務端已消耗的額度。只前進 tick、相關資料不變時，正常套用回覆。

此檢查針對休閒與見面約定，不涵蓋所有背景、關係、經濟與環境資料，也不判定任意模型台詞的語意正確性。保留原有換鎮／角色離開／過世保護。
