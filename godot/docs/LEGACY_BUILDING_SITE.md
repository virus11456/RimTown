# 已完工舊工程補選址（2026-09-11）

舊存檔有已完工工程、但沒有 3D 座標時，現在可在「小鎮 → 建築工程」找到「補選址」按鈕。先預覽空地，再確認；取消不改存檔。補選址只填入位置，不重建、不再扣材料、不增加工量，也不重複發放防禦／農務等效果或完工獎勵。

旅人仍需現任鎮長核准位置決策。確認後至「鎮務提案與權限」查看提案，核准後執行；玩家當鎮長時可以直接決定。核准內容指定工程與座標，執行時再檢查空地、工程狀態、核准期限與現任鎮長。核准期間存檔重載後仍可照核准位置執行。

保留原本建築識別、名稱、等級、工量與效果。病房、瞭望塔及農田灌溉補上座標後，接入實際工作場所；原有診所／守衛站／農場不被替換。已經有座標的工程不能用此功能任意搬家，正在升級時也不提供補選址。

適用有唯一工程識別、已知建築範本、完工狀態且兩項座標都缺少的非住宅工程；資料不完整或不支援的舊工程不猜測修復。住宅涉及居民住處分配，不套用這次工程補選址。
