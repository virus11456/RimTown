# 聊天承諾與行程變更一致性

自由交談、主動事件評論、真心話共用送出時的行程快照，回覆抵達後重新核對。新增居民彼此的同行資料：待出發安排、目的地、期限、已出發／到場的人、暫停與取消原因，以及參與者的飢餓、疲憊、避難與活動狀態。資料與玩家邀約分開，單方到場不代表雙方碰面。

- 自由交談若資料已改變，整筆回覆與好感、戀慕、意圖、記憶及邀約效果不套用；保留草稿並說明需要重新傳送。
- 主動評論與真心話也核對玩家約定及工作場所。舊 AI 台詞失效時只完成原事件的本機台詞，不從舊回覆新增邀約；原事件仍按既有規則留存一次。
- 快照不共用可變的行程陣列，也不比較每幀位置或同行倒數。時間前進而事實相同的回覆仍可接受；沒有自動 API 重試。
- 讀檔或換城沿用既有請求世代隔離，舊回覆不能修改新世界。
- 自由聊天資料超過預算時，縮減提示明確禁止猜測位置、行程與作見面承諾；原訊息和效果格式保留。

## 驗證範圍

新增雙城 306 項檢查，使用實際介面請求回呼與模擬 AI 回覆，涵蓋自由交談、事件評論與真心話中的取消、暫停、恢復、到場、改期、同行者需求與避難、玩家約定及場所變更；同時檢查倒數正常前進、無重試／重播、讀檔和換城。自由交談以完整世界快照驗證舊效果不套用。

既有主動邀約測試改走應用程式讀檔，維持實際位置觀察連接；原本直接重載核心會使介面重建時才補回位置，導致測試內行程資料意外改變。延遲邀約遇到新約定的預期更新為本機台詞；新約定保持不變。這是測試前置與新行為預期調整，不放寬遊戲赴約規則。

最終共 1301 項檢查通過（新增雙城 306 項及 11 組既有回歸 995 項）。各回歸結果見 CONVERSATION_SCHEDULE_REGRESSION.json。這包不呼叫正式 AI 服務，也未重跑兩城五日耐久；不能保證模型每句自然語言都絕對正確。自然赴約與施工的上一包紀錄仍見 DUAL_TOWN_SOCIAL.md。

本包為 Godot 本機測試版，未推送 GitHub／Vercel。下一包整合主動聊天與實際赴約的自然時間推進，觀察正常作息中回覆失效比例與重試體驗，再處理經驗不足的分支；不拆成每個小項目驗收。
