# 守衛依人力輪班（2026-09-11）

依使用者要求，夜間守衛值勤屬正常行為；不是每鎮都必須有兩人。

## 規則

- 只為現有、存活、非玩家的守衛安排班次，不新增居民、不更改職業、不扣發資源。
- 首次排班：一位守衛預設日班；兩位以上依現有人力分配日夜班。邊境鎮原有楊鋒為日班 06–18，高朗為夜班 18–06。
- 已保存的有效班次優先保留；若剩下一位夜班守衛，仍保留夜班，不憑空補一位日班。零守衛也不新增。
- 跨午夜工時與通勤、休閒、聊天約定、行程頁共用有效班表。夜班預留白天睡眠及往返通勤；仍須真的走回自己的房間、停下後才能睡覺，沒有瞬移或提高步速。
- 沒有哨站時使用現有廣場作為臨時值勤處；哨站存在後改用哨站。沒有免費建造設施。
- 醫生、農夫缺少診所／農田時，正常清醒上工時段標示等待工作場所，不再往不存在的地點移動。緊急需求仍優先；本包未調整每日產量系統。
