# 居民同行等待與短暫協調

已出發的居民在原到場期限內保留目的地，避免一般閒暇作息重新選址。實際到場的一方顯示等待同行者；雙方實際同地且近距離才完成。赴約／等候使用獨立活動，不把途中當成已在社交，也不額外給工作經驗或物資。

遇到急迫飢餓、疲勞或正在進食／休息，雙方最多暫停一個遊戲小時，回到一般作息處理需求。只有雙方都恢復可用才繼續原地點；每次同行只允許一次休整，原到場期限不延長。再次中斷或未能及時恢復就取消。工作、通勤與睡眠時段、玩家約定、自主休閒、死亡和避難等衝突仍直接中止，不等待高優先行程結束。

暫停狀態、期限與已用機會隨存檔保存。暫停期間即使兩人在同地也不結算碰面；恢復只設定目的地，實際位置仍由原行走路徑推進。介面顯示等待、暫停與恢復原因，375px 寬度檢查通過。

這是本機規則的短暫協調，沒有生成式談判或自動改約明天。完整模擬受食物與作息影響，不保證一小時足夠恢復；期限到便如實取消。後續工作包：用原始居民連續多日驗收提議、同行、等待、完成／取消比例，再根據實際失敗原因調整。
