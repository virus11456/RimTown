# 自然多日驗收與仍未達標的項目

此包使用原始邊境鎮，正常遊戲時鐘與每 tick 120 個移動 frame，連續跑 32 日並在第 16 日讀檔恢復。沒有提高好感、補需求、修改職業、搬動座標、注入邀約或呼叫正式 AI。每天另以唯讀方式記錄玩家邀約的合法候選時段；這份候選清單不是玩家真的接受或赴約。

## 找到並修正的問題

- 自主休閒更新會提前返回，跳過已到場居民的交談。現在 attending 狀態可進入原本交談流程，仍由同一實際場所、近距離及原冷卻規則把關。
- 工作中的居民也不會進入交談流程。現在僅在有場景觀察、居民停止走動且需求不緊急時，允許與實際近距離居民交談；工作活動、原始對話內容／好感計算、冷卻及邀約機率不變。沒有新增資源獎勵。
- 八位居民的實際分配住家位於擴建區，與其邏輯住宅區名稱不同。原回程檢查誤拒絕這些住家；現在依地圖既有住家分配判定，仍拒絕不存在的住家或地點。初始 20 位居民從廣場、公園都能找到回到實際住家的路線。

單補休閒交談仍未產生自然交談，因此另補工作場所交談；這不是把回程限制放寬。新增受控測試涵蓋實際近距離、移動中／遠距離拒絕、社交關閉、原冷卻、維持活動與資源，以及擴建住宅路徑。

## 進一步的平衡問題

普通步行速度與目前遊戲時鐘比例下，從廣場到住家估計需 2.5–7.25 個遊戲小時；加上原有兩小時等待期限、工作及睡眠，大多數居民沒有玩家邀約空檔。不能靠提高邀約機率、假定已到場或瞬移來掩蓋。

下一包優先校準遊戲時間與普通步行距離的比例，並同步核對通勤、赴約和返家估算；保持角色畫面上的慢速步行，再重跑多日驗收。自然休閒沒有完成的問題一併列入，不能只以受控 fixture 通過宣稱自然行程完成。
