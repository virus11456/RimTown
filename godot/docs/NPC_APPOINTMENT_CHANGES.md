# NPC 工作衝突改約第四包

當已接受的約定因 NPC 工作時段變更而衝突，居民會先找新空檔，再提出改約。新日期為原約定的隔天（若原日期已過，至少是明天），從既有 08–19 點選項找可見面的時段。無空檔或本約定已改過一次則取消，保留原因。此功能使用本機規則，不消耗 AI 額度。

新狀態 change_offered 仍占用唯一活動約定名額。原 due／hour／time 不變，新時間放在 proposal；原約定暫停，不會繼續導引 NPC，也不能靠舊地點的邏輯位置完成。角色主動說明工作衝突與建議日期，雙方的記憶明確標示尚未同意。

玩家從「居民 → 見面約定 · 待回覆」按「同意新時間」才生效；按「婉拒改約」或兩個遊戲小時未回覆，原約定取消。介面明示原約定已暫停，不把婉拒解釋成維持舊約。接受當下重新驗證對方、地點、工時與需求；新時段又有衝突會取消，不再連續改約。接受後與玩家主動順延共用一次限制，保留原日期歷史與雙方確認記憶。

死亡、避難、急迫需求與無路可達維持原本取消／失約流程，本包不讓 NPC 宣稱知道何時病好或避難結束。尚在等待的約定也不自動展延。
