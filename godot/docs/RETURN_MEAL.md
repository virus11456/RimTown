# 返家途中進食與期限校正

前包王麗兩次返家任務在 tick 145／721 被記為到期。第一個原始流程重播顯示：tick 138 碰面後返家，140 飢餓降到 14.4，141 轉向酒館進食，142 恢復返家；144 已走到住家入口附近，145 的移動階段才停在自己住家。原期限在 145 開始就失效，因此「任務到期」不等於她沒有回家或被瞬移。

本包不改動進食、走路或實際到家時間。碰面後返家途中完成一次進食、飢餓已恢復時，從當下實際位置重算剩餘回家路線；只在剩餘時間不足時校正期限，最多增加四個 ticks（一遊戲小時），每次返家任務只准校正一次。原始期限、校正時刻與增加量保存在任務中，讀檔及重複呼叫不再延長。

過期任務不復活，住家改變、位置缺失、無路徑、玩家、死亡、避難或仍飢餓時不套用。工作／需求／睡眠等原優先權仍由正常流程決定。這是返家任務的有限容錯，並未延長同行出發／碰面期限，也沒有新增食物、精神、資源、獎勵或更快步速。

## 原始快照重播

`WANG_RETURN_REPLAY.json` 是修正前正常模擬第一次碰面時的 app 存檔，另保存該 tick 剩餘的移動 frames。`RETURN_DIAGNOSIS_BASELINE.json` 保留修正前逐 tick 診斷。重播不修改需求、班表或位置：王麗仍於 tick 145 到家，進食後估計返家期限由 145 校正為 147，只增加半小時。最大單 frame 位移 0.958 像素；途中再存讀檔，校正量保持一次。

123 項修正與回歸檢查通過，包含 23 項期限與副作用檢查、6 項自然快照重播，以及共同休閒、一般返家、同行實際行走、玩家邀約、睡眠中斷與實際到家休息。另保留一項修正前基準快照擷取檢查，不混作修正驗收。

八日自然測試另增加「所有觀察到的碰面後返家均在有效期限內到自己住家」斷言，並依任務實際保存的期限追蹤，不再固定使用建立時的舊期限。結果保留於 `RETURN_MEAL_ENDURANCE_TESTS.json`，聚焦與重播結果為 `RETURN_MEAL_TESTS.json`、`RETURN_MEAL_REPLAY_TESTS.json`。

## 八日自然結果

739 次交談、6 次提議、6 次實際碰面，與前包相同。12 次碰面後返家均實際停在自己住家、在校正後的有效期限內完成，最大單 frame 位移約 1.000 像素。王麗兩次到期案例的期限由 145→147、721→723，兩次仍在 145／721 的移動階段到家；不是縮短了她的實際回程。

9 次回程依進食後剩餘路線增加 1 或 2 ticks（十五／三十分鐘），另外 3 次沒有增加。所有校正都在每次最多一小時且只一次的限制內。8 項自然檢查通過，合計修正與回歸 131 項。

這是原始八日樣本，不是所有地圖、職業、極端需求或長期存檔的保證。下一包接續逐居民的通勤遲到與有效睡眠檢查，並保留自然同行、進食繞路與實際返家的回歸。
