# 依實際經歷的日常回憶搭話

日常主動搭話現在會優先提到同一居民最近一次已結束的約定：實際碰面、未碰面或取消。來源是 appointments.history 的結算狀態，不把自由對話或一般記憶文字中的承諾當作已執行事件。

新約定結算會記錄 resolved_tick。至少隔 96 tick（一天）、最多 672 tick（七天）才可在原本合格的近身閒暇搭話中提起；每件事只提一次，保存最近二十個已提過的來源鍵。只看該居民最新已結束紀錄，若最新太近／已提過，不翻出更舊的事情補上。舊紀錄沒有結算時間則跳過，不能推測何時發生。

碰面時只表示記得那次見面；對方確實未抵達時才說自己沒趕到，已到場但未碰面時使用中性的「我們沒能碰上」，不猜測玩家失約原因；取消則簡單關心近況，不自行追究誰的責任。台詞仍為本機規則，不是連線 AI 反思或自由生成。

共用既有每日兩次、四小時間隔、同居民每日一次、實際距離／場所以及聊天／值勤／邀約讓路規則，不新增額外搭話、不給予資源或好感獎勵。使用「日常主動搭話」設定一併關閉。

聊天紀錄保存 _godotRecall 的來源居民、結果、原時間與結算 tick，供驗收追溯；雙方仍以既有記憶流程記下本次搭話，後續自由聊天可透過原記憶檢索讀取。來源標記不會作為角色台詞顯示。

## 驗證

TALK_RECALL_TESTS.json：結算時間來源、一天／七天範圍、實際近身搭話掛鉤、一次性與重載、最新紀錄優先、不同居民隔離、失約中性敘述、舊檔不猜測、純文字不算證據，以及資源／關係不變。

TALK_RECALL_UI_TESTS.json：載入原先廣場等待檢查點，玩家實際沿碰撞路徑赴約完成見面；正常推進 96 tick，再配置閒暇場景，玩家重新走近，從日常搭話與聊天頁看到該次見面的回憶。375px 介面與交付壓縮檔原生重載驗證通過。回憶事件不是直接注入的完成旗標；第二次閒暇機會的職業／需求／活動為明示測試設定。

outputs/居民記得上次見面.rimtown 保存已發生回憶搭話的測試場景，載入後從「居民 → 最近搭話」查看；重載不會反覆提同一件事。原搭話、邀約與玩家改約規則回歸通過。

尚未包含職涯／其他生活事件的回憶搭話、完整自我反思、長篇對話或生成行程；不能把此包稱為所有居民記憶皆已轉成行為。
