# 休閒行程與自由交談

居民自由交談頁新增「詢問休閒安排（本機）」。這是讀取遊戲紀錄的預寫回答，不用 API 或 AI 額度；不修改好感、技能、任務、需求、資源或行程。保留輸入草稿，等待 AI 回覆時停用；過世居民不回覆。連續詢問相同資料不重複寫入對話，讀檔後仍去重。對話保存 `_godotLeisure` 來源，並標記本機台詞。

尚未排定、排定／行走／停留中、已完成、未完成、取消與沒有空檔各有明確回答。只有完成狀態才說已實際停留三十分鐘。舊日期安排不冒充今日行程。這個按鈕沿用自由交談頁的可用範圍，不新增遠端赴約、同行或實際面對面條件。

自由交談的 AI 提示帶入同一份有長度限制的當日安排及最近兩次結果，包含狀態、原因與調整理由，明示未完成不能說成完成、文字備忘不是行動、休閒不是與玩家的見面約定，且資料不提供目前精確位置。超長提示退回精簡格式時保留本機核對結果。這次只接自由交談，事件評論、真心話及其他生成通道未全面接入。

此包不攔截或證明任意模型輸出的語意正確性。正式 AI 未呼叫；沒有把自由文字承諾變成新行程。可直接驗證的保證是本機回答與結構化狀態相符。
