# 道路封閉與停止踏步

2026-09-11：修正 3D 自動行走正面撞牆時，沿牆分支可能把零位移誤當行走的問題。碰到不可通行的下一步，先停止行走動畫，再重新規劃；有繞路就走繞路，找不到路則保持原座標。

等待期間每 60 個固定移動幀後重試一次（正常 1× 約一秒），清除舊尋路快取，不因等待而瞬移。目的地改變時立即取消原來的等待。門口與進出建築流程仍使用原本的路徑目標；旅人鍵盤操作保留原來沿牆滑行。

居民卡片與今日行程新增「前方受阻，目前找不到可通行路線」說明，與「目前位置不可通行」分開。查閱時重新核對路線，不因存檔的舊等待旗標或過期快取而繼續顯示封路。顯示找不到路不代表數學上證明不存在路徑，仍沿用原尋路搜尋上限。

新測試使用受控直牆：十秒保持原座標、停止踏步；在牆上重新開通一格後會按原速走過缺口並抵達，最大單幀位移 0.804 像素以下（包含原有不足一像素的路點收尾）。另外核對附近繞路、改換可達目的地、JSON 等待狀態、無資源／記憶異動，以及 375px 居民卡片和行程頁。

證據見 BLOCKED_ROUTE_TESTS.json、BLOCKED_ROUTE_UI_TESTS.json。受控開口不是新增拆牆玩法；本包不保證任意損壞地圖都能恢復，也未新增救援瞬移。
