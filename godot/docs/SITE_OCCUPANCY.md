# 新建與擺放的實際占位保護（2026-09-11）

一般新建工程、裝飾擺放與舊工程補選址共用即時占位檢查。確認或執行時，用地及周邊半格內若有居民或旅人的實際位置，就暫緩，顯示「用地附近有人，請等他離開後再試；未扣材料」。檢查建築的 2×2 格與裝飾的 1×1 格，不把遠處居民算成占用。

預覽只是選位置，不保留空地。即使預覽或鎮長核准時沒人，最後執行仍重新核對；被擋下時不扣料、不建工地、不擺裝飾、不移動角色，也不新增提案。已核准案件保留核准狀態，等人離開後可再執行，仍受原期限及鎮長權限約束。

占位提示只顯示原因，不把它誤當成鎮務提案、不跳去提案頁，也不將這次拒絕標成已更動世界。真正的提案及核准流程保持原樣。對外操作與內部最後執行步驟都有檢查。

## 驗證

新測試以受控角色位置與材料，驗證居民／旅人、建築／裝飾、公開及內部執行、預覽後有人走入、手機訊息、人離開後重試、半格邊界，以及核准後才被占位。拒絕前後比較完整世界及所有角色位置，確認沒有變動；重試只建立一件工程並扣一次原本材料。

1704 項檢查通過：新占位流程 17、既有選址 338、舊工程補選址 24、裝飾與組合 1202、治理核心 35、治理 UI 19、農務 24、瞭望塔 23、病房 22。重跑項目只計一次。既有工作場所上工、返家、讀檔及治理案例均通過。
