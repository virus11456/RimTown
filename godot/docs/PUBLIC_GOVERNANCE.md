# 公共資源與旅人權限

依使用者決定：不新增個人錢包或背包。銀幣、材料與工廠存貨皆屬於小鎮公共資源。

## 操作
- 未當選的旅人：建設選址與升級、產業、工廠、配方、人力、研究方向、排班、播種施肥、裝飾、商人交易、工廠出貨／訂單改為提案。提出時不扣料、不開始工程。
- 小鎮 → 鎮務提案與權限：顯示現任鎮長、具體用途／位置／報價／預算與審核理由。每天午夜按先後審一案，同時最多三件待處理。
- 鎮長依兩天糧食保留、銀幣預備金 20、現有庫存及其他核准預算審核。缺糧優先糧食供應用途，會拒絕賣光口糧；這是明確本機規則，沒有呼叫 AI 審批。
- 核准後三天內點「執行核准案」，執行時再檢查工程／商品／人手等實際條件並扣公共庫存。授權綁定用途、數量、報價及核准鎮長，只能成功執行一次；換任或過期需重新提案。商人离開、材料不足或空地被占用時不保證可執行，可撤回重提。
- 選舉當選鎮長的旅人可直接決策，失去鎮長職位後恢復提案限制。無鎮長時提案暫緩，不能自行批准。
- 澆水、收成、清理枯萎農地屬幫忙勞動，仍可直接操作。既有鎮民每日生產、研究及自動排班是城鎮既定運作，不因旅人未當選停擺。

## 公共慰問
每位居民每日一次，全鎮共兩份；不發銀幣紅包，不增加戀慕。一般好感 +2，符合偏好 +3；記憶、聊天與公共帳本明記「代表小鎮」。沒有把公共物品偽裝成玩家私產。

## 保存與驗證
正常介面新舊存檔預設開啟治理；Godot 比對原版的純模擬仍保留明確關閉模式。旗標、提案、審核、期限、核准使用狀態與慰問額度存於 _godot4a／quest_balance，不改原版存款欄位。AI 自由對話也帶入公共所有權及旅人提案限制。
