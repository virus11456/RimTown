# 居民日常主動搭話

一般遊戲預設開啟本機主動搭話，每次 app 模擬 tick 檢查實際 SimMotion 位置。玩家與居民必須在同一實際場所／住家，距離不超過 48 px；currentLocation 目的地相同不代表可以交談。只在 08:00–21:00，居民處於閒逛、社交、娛樂或休息活動，沒有工時、飢餓、疲勞、避難或死亡衝突時觸發。社交需求 ≤60 或對玩家好感 ≥25 才願意開口，好感為負者不主動搭話。

全鎮每天最多兩次，同一居民每天最多一次，兩次之間至少 16 tick（四個遊戲小時）。選最近的合格居民，距離相同以 ID 穩定排序，不抽取世界 RNG。依當前心情／熟悉程度選本機句子，連續相同話題改用當季問候，不捏造已完成的工作或交易。

既有事件評論待發、活動邀約、玩家值勤、聊天／耳語／送禮／約定頁、聊天請求進行中或匯入視窗開啟時讓路，不強制打開面板、停止移動或暫停世界。狀態列提示「某居民向你搭話」，居民列表提供「最近搭話」按鈕接續自由交談。雙方記憶及玩家聊天紀錄同步保存；不主動發放資源、好感、戀慕或技能，不消耗 AI 額度。

設定頁「日常主動搭話」可關閉；開關與 daily_talk 頻率紀錄保存在 quest_balance。切換開關與重載不清除已用額度。此功能只在帶有實際位置的 app 端觸發，純 SimWorld.tick 不會憑邏輯位置生成搭話。

## 驗證

DAILY_TALK_TESTS.json：受控位置、不同場所／距離、工時／活動／需求／關係限制、每天額度、間隔、同居民限制、重載、話題變化、雙方記憶與資源／關係／RNG 不變。

DAILY_TALK_UI_TESTS.json：受控閒暇居民場景，玩家沿碰撞路徑走近後，以正常 app tick 觸發搭話；驗證草稿、連線請求、匯入視窗保護、不強開面板、最近搭話按鈕、375px 顯示、原生壓縮存檔載入與關閉選項。這是 headless 位置與介面驗證，不是角色動畫或正式 AI 品質驗收。原自由交談介面與邀約規則回歸另驗證。

outputs/居民日常搭話.rimtown 是已發生一次搭話的受控閒暇測試場景（包含測試用職業／活動設定），載入後從「居民 → 最近搭話」查看。一般遊玩可直接開新版新局使用此功能。

本包不是連線模型自主推理，也未包含日常自動邀約、反思／生成行程、持續對談或完整生活故事；使用者主動接續自由交談仍沿用既有聊天模式與額度。
