# 赴約引導

接受邀約或對方等待時，約定頁新增赴約狀態：距離時段結束的剩餘遊戲分鐘、旅人是否實際在約定場所、對方是否實際在場所。只改 currentLocation 不算到場；進入同一場所也不代表已完成，仍須到約定時間後依原近距離規則碰面。資料隨既有遊戲 tick 刷新。

「查看約定地點」將鏡頭移到該場所中心，解除鏡頭跟隨並收起側欄，手機也能看到地圖。玩家仍自行操作旅人；不移動任何角色、不自動赴約、不改時間或資源。邀約未接受、已暫停等待改約或已結束時不提供此引導；失效按鈕回呼也會再次驗證。原本到時後固定顯示等待兩小時的文字改為實際剩餘時間，期限已過時明示等待結算。

這是地點查看與到場資訊，不是畫出路徑、導航箭頭或自動尋路，也不估算玩家行走所需時間。
