# 職業玩法與任務指南

職業與值勤頁新增指南，設定頁也可進入。11 種職業都能先預覽玩法、開始方式及該職業已記錄的職涯階段，不必先登記轉職。玩法文字與實際值勤頁共用，進度及所需停留時間讀取現有職涯紀錄。

值勤頁把實際任務、開始按鈕與進行中的取消按鈕排在其他職業登記清單前面，避免必須先滑過所有轉職選項才找到工作。

- 農務、工程、研究：只有真實需求才列出工作，親自到場，適用時走到操作台。
- 守衛：依值勤頁列出的三個巡查地點逐一完成。
- 醫護、牧師：走近有需求的居民，保持三格內與同一場所，必要行程可能使服務中止。
- 採集、餐食、工具、衣物與交易：依需求、備貨及公共用途核准開始，不為職涯增加無需求產量。

所有職業共用每日三次完成值勤額度，轉職不重置。成果歸小鎮，沒有個人錢包。鎮長可預覽其他玩法，但不會藉預覽或登記卸除職務；指南另提供處理鎮務入口。

## 如何操作

打開「小鎮 → 職業與值勤 → 職業玩法與任務指南」，選「了解」預覽職業，再按「前往目前職務與可做工作」回到真實任務頁。此按鈕回到目前職業，不替你改成正在預覽的職業。需要轉職時，使用值勤頁底部的明確登記按鈕。

指南顯示下一階段所需的有效值勤、不同日期與職業專屬條件；只有實際完成才計入。閱讀不初始化值勤帳本、不申請材料、不發獎勵、不移動角色。

驗證：98 項指南專項涵蓋 11 職業、桌面／手機、只讀預覽、真實任務順序、導覽與鎮長職務保留。9 組整合合計 523 項通過，含實際值勤、升階、生產材料核准與交易。修正舊生產介面測試的過時核准文字，並同步驗證真正核准狀態。
