# 最終路線選擇與主線整合

一般 Godot 試玩現在會保留最終主線的達標進度，等待玩家在「故事 → 任務與人生 → 主線」按「選擇結局」。未達標按鈕停用，多條達標時不再以資料排列順序自動選第一條；可繼續遊玩追求另一條。

沿用原版條件鎖存：各項目曾達標便保留，不要求最終點選當下同時持有所有資源，也不額外扣交資源。已完成舊存檔不重開結局、不重發任務獎勵。待選狀態會存檔，選定後凍結當時統計。

沿用婚姻覆蓋：已婚選繁榮／和平路線呈現個人結局，UI 在點選前告知；傳奇維持傳奇。純模擬來源對照預設仍沿用自動結局，透過 finale_choice_enabled 隔離測試相容性。一般新局及沒有該欄位的舊存檔，主場景預設啟用手動選擇。

繁榮度修正：防禦與美觀維度讀取新建築的 buildingKey，保留舊 key 相容；town_walls 納入防禦。實際付費並完工的瞭望塔、花園已驗證計入。

## 一條完整主線路線

MAIN_ROUTE_PROGRESSION_TESTS.json：原始示範資源、旅人身分、預設原料補給，啟用社交、突襲、年度選舉、經濟與人口。依正常審核發展產業、建築、工廠與播種；作物實際生長並收成。每天呼叫三位居民的原離線對話規則，不直接設定好感或任務完成條件。

第 130 天完成 12 個主線、3 次收成，人口 41（含玩家）、Lv7、20 棟建築，12 次突襲結算，最後由選擇 API 選定傳奇結局。沒有注入金錢、好感、人口、建築進度或已完成任務。此為腳本操作遊戲模擬 API 的整合測試，尚未包含逐段 3D 步行、所有 AI／生命週期功能、全部替代路線或婚姻自然操作。不能稱為全結局自然通關。

主線腳本另外輸出選擇前存檔 main-route-ready.json.tmp（不進 git／專案 ZIP），複製為輸出目錄的第130天結局前.json 供人工試玩。

FINALE_CHOICE_TESTS.json 與 FINALE_CHOICE_UI_TESTS.json 使用明示達標 fixture，驗證三種可選路線、婚姻覆蓋、未達標防護、重複結算、待選存檔、375px 介面及實際建築繁榮度。此類 fixture 不與上述一條主線進程混稱。
