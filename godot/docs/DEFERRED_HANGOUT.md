# NPC 同行共同空檔預約

工作中近距離交談已能發生，但原邀約只檢查從交談當下開始的空檔，會拒絕仍在上班、稍後即下班的居民。本包讓邀約挑選短時間內可共同出發的空檔，不讓居民在工作時直接離開。

## 規則

- 只在原本好感門檻、交談冷卻、12% 邀約機率與無既有同行的條件成立後，檢查現在到最多 2.5 遊戲小時後的共同空檔。
- 每個候選仍按實際路線檢查往返、睡眠與工作。等待時間會扣除原本六小時的碰面期限；提議仍須在原本四小時內開始出發，沒有延長期限。
- 雙方保存同一個最早倒數時間 `not_before`。即使提早空閒或倒數值已為零，也不能早於預留空檔出發；工作、需求、既有休閒、玩家約定、避難及返家仍優先。
- 原倒數開始後仍只在雙方可用時推進，同 tick 不重複扣除，存檔保留等待時間。舊提議沒有新欄位時沿用原行為。未到場不寫碰面完成記憶。
- 日誌與提議記憶標示預計幾點後有空再出發；不宣稱已到場。不增加產量、資源、獎勵或邀約機率，也不加快步速。

## 驗證

111 項聚焦與回歸檢查通過，包含實際邀約生成、共同空檔、未到時間拒絕出發、倒數／存檔、原期限取消、實際到場條件、需求暫停及返家路線。新測試使用受控近距離木匠搭檔及提高好感，不能當成自然同行成功率。

自然八日結果另記於 `DEFERRED_HANGOUT_ENDURANCE_TESTS.json`：沿用原始居民、正常班表與需求，每 tick 480 移動 frames，第 4 日重載，沒有注入邀約、提升好感、移動座標或呼叫正式 AI。

其餘六筆均在出發前到期，沒有偽造碰面記憶。逐 tick 足跡中，六筆都包含工作後的 `planned_leisure` 阻擋，部分另有進食；尚不能宣稱所有邀約都能成行。下一包優先處理同行候選與既有自主休閒的時段衝突，在提議前核對完整行程或合理協調同地活動，保留工作、睡眠、明確玩家約定與既有期限，不直接刪掉休閒優先權。

本包為八日樣本，未重跑 32 日或全遊戲通關。報告含提議、逐 tick 足跡、共同到場與兩人返家終點，供後續回歸比較。
