# 長路程分段赴診

2026-09-13。本包將旅程與到場照護分開，不建立跨日固定預約。

## 新流程

舊流程把步行、到場確認與照護都塞進八刻內（兩個遊戲小時），使部分有空檔的遠處居民不能出發。現在依實際門口路線，以正常步行預算估算旅程，再加一刻到場確認餘裕；步行預留最多十六刻（四個遊戲小時）。這是上限，不是每趟都預留四小時。

出發前仍預估整段旅程與兩刻照護的飢餓／體力、服務者在班、居民工作／睡眠、既有約定及返家路程。檢查失敗就暫緩，不消耗當日求助次數。通過後存下固定抵達期限與整體期限；正常走路，到同室近距離且停步後才交談，開始兩刻（半小時）照護。

抵達期限包含最後一刻，到場後仍保留完整照護時間；超過抵達期限便中止。整體期限固定，不因每刻更新或讀檔向後延。工作、睡眠、飲食、玩家介入、服務者離開等原有中止條件繼續優先。仍是一位服務者同時一人，每日最多完成三次。

行程頁分別顯示步行抵達餘時與照護餘時，明確標為遊戲時間。旧存檔未帶分段資料時沿用舊的絕對期限，不自動加時。

## 控制驗證

兩鎮各兩個職業，選擇原地圖中超過舊八刻總期限的實際路線，控制需求與服務者狀態後，以真實模擬 tick 和碰撞移動走完。四組皆觀察到步行、到場停留與單次完成；預留步行為六至八刻，途中實際存檔載入後仍接續，逐影格移動不超過正常步幅。

另驗證最後一刻抵達、未抵達逾時不給效果、固定期限不滑動與舊格式存檔不延長。原生截圖為控制情境，區分旅行與現場照護提示，不作為自然接待證據。
