# 居民依行程結果調整安排

本包延續自主休閒安排。每位居民保留最近七次有結算的行程結果，包含原日期、時段、場所名稱、完成／未完成／取消／無空檔及原因。排定或只到達目的地不會被記為完成。每天最多一筆，跨日關閉仍未完成的舊安排，移除居民時清除其紀錄；存檔保存結果與本次調整依據。舊存檔不虛構過去成果。

如果最新結果是兩個遊戲日內未完成實際到場停留，隔天優先嘗試早於上次的可用時段（09、10、12、14、16、18、19 點）。仍須滿足實際工時、通勤、睡眠與至少一小時後開始；沒有較早空檔就沿原有候選時段選擇並說明限制。取消、成功或過久的結果不觸發提早；當日不重新抽排，也不增加次數或物資、銀幣、經驗。

居民「今日作息與行程」新增安排理由與最近三次休閒結果。這是可追溯的本機規則式調整，不是生成式 AI 反思，也不推論居民失敗的心理原因或保證下一次成功。更多活動、NPC 間共同約定與完整生成行程仍待開發。
