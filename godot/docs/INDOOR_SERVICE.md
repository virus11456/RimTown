# 室內拜訪與服務

醫護／牧師從職業頁查看服務對象行程，可查看居民目前位置或目前房屋入口。入口依居民實際所在的住家／建築取得，不使用預定目的地或分配住家；保留舊按鈕後居民移往戶外，再按也不會指向舊房屋。查看只移動相機。

操作：登記醫護或牧師 → 查看有需求居民的目前行程 → 查看目前房屋入口 → 用 WASD／方向鍵穿過門口 → 走近居民 → 返回職業與值勤開始服務。方向相對目前相機。服務中需持續同一房間、三格以內；居民恢復需求、任一方離開或進出門均會取消，不發技能與每日額度。每日共享三次限制保持不變。

住宅原本已有可通行門口，本包沒有新增傳送或自動尋路操作。新增依實際地圖門檻格判定的服務限制，避免手動移動清除 doorPhase 後，站在門檻仍能開始服務；停步及重載同樣適用。

驗證：INDOOR_SERVICE_TESTS.json 共 323 項；兩鎮全部現有住宅與具有入口的公共建築，以實際手動碰撞移動走入、走出，合計 8,946 個移動影格，最大單步 1.201 像素以下、無不可通行落點。醫護與牧師涵蓋室內完成、旅人離開、居民離開、不同住家、門檻停步／重載、值勤中重載、入口過期與 375px 介面。九組既有職業及行程回歸全部通過，見 INDOOR_SERVICE_REGRESSION.json。

範圍：需求、起始位置與結算時間為受控測試；居民離開案例直接設定目標位置以隔離取消判定。這不是自然多日室內服務通關。原生重載會正常清除行走按鍵與步行動畫，已停步存檔的世界／實際位置／進行中值勤完整保留。沒有呼叫正式 AI。

後續：將室內拜訪納入自然多日追蹤，評估居民回家休息時照護需求消失的可玩性；繼續職涯分支內容與工作動畫。官網整體風格評估保留於後續佇列。
