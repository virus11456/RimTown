# 操作台到位與四日整合（2026-09-12）

職業頁新增「走到操作台」：玩家提出前往要求後，旅人使用原尋路及碰撞移動，逐步走到精確標記；到達後開啟職業頁，仍由玩家按「開始」值勤。原本只定位鏡頭的「查看」按鈕保留。

方向鍵／WASD 可隨時接手；職業頁有停止按鈕。轉職、需求消失、工作台改變、開啟輸入框／檔案對話框或讀檔時取消暫存的前往指令。到達不會自動開工、扣料或得到經驗。路線不寫入存檔，存檔保留實際腳下位置；已站在目標格時也能完成控制權交接，不會因尋路回傳空路線而被拒絕。

- 新增 878 項斷言通過：五種操作台職業、兩鎮現有設施，實際介面按鈕、763 個有界碰撞移動樣本、到達後明確開始、手動接手、停止、途中讀檔、需求／職務改變、原地到達，以及各可用職業的午夜中止和額度重設。
- 既有十組回歸共 17,424 項斷言通過。含操作台姿勢、家具邊界、職業介面、室內服務及不同職業動作；大量項目是幾何取樣，不代表相同數量的獨立玩法。
- 原生三例：邊境鎮木匠、裁縫與海風鎮研究員，共 259 移動幀，六張行走／到達圖片，代表圖片已目視確認。到達時沒有自動開始工作，最大單步約 1.20 像素。

## 兩鎮各四日的自然整合

原始資源與居民作息、正常鎮長核准及原價扣料施工，合計 368,640 個移動影格。沿既有職涯整合案例，玩家先巡查，再在有工房的邊境鎮請求步行到台進行一次木匠協作，之後繼續巡查；海風鎮不補工房。

兩鎮都維持每日最多三次共用值勤、值勤中與跨日讀檔正常，沒有不可行走格、異常位移或負庫存樣本。四日從日間起算會跨越五個曆日，不能把五筆每日額度記錄解讀為模擬了五整日。
