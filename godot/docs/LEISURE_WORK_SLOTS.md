# 下班後的休閒時段調整

前兩日逐居民診斷顯示，未完成者包含期限前仍在路上的居民，以及已在公園但只累積零或一段停留的居民。資料見 LEISURE_WORK_SLOTS_DIAGNOSIS.json。這些觀察不能全部歸因於卡路徑；本包不修改移動或使用瞬移，也不延長停留判定的容許缺口。

修正時段選擇：最新近期結果未完成時，仍先找更早的合法空檔；若沒有，嘗試較晚候選時段，最後才重試原時段。這讓全天工作的居民有機會在下班後多留一小時趕路。最新近期結果已實際完成時，優先沿用成功時段，避免隔天又自動回到失敗時段。兩種依據都只採最近兩個遊戲日的結算，原工時、通勤、睡眠、每日一份及存檔限制維持。原時段因職業或睡眠改變而不適用時另選合法空檔。

行程頁及本機詢問原有的安排理由會呈現「試較晚時段」或「沿用成功時段」。沒有個人錢包或額外銀幣／商品；完成後的既有休閒需求回饋不變。原行程調整文件的「只有失敗作為依據」由本包的成功沿用規則取代。
