# 防禦事件

2026-09-10。一般試玩預設啟用，「故事 → 小鎮防禦」查看預警及決策，可關閉後續突襲。純來源相容測試預設停用。

採用原版四種敵襲資料。每天判定，預警至少隔五天；一天後未回應由鎮長自動應變。旅人提供建議，NPC 鎮長依守備與預算採納或拒絕；玩家當鎮長可直接下令。

全力防禦：NPC 守衛、建築、政策與玩家巡邏加成，加隨機 1–3；有可出勤 NPC 守衛才再加 3。勝利才計入抵禦任務，沒有免費戰利品。失敗損失公共物資。求和：威脅 ×15 公共銀幣，不算勝利。疏散：損失食物、木材、石材各 15%，非守衛居民在家避難至翌日，不參與主要工作。產業原有無人力基礎產出仍保留。

預警不先扣資源；結算僅一次；預算不足的玩家求和指令不修改世界。避難居民不移除／重建，關閉突襲也會恢復工作。這修正了原版先結算才選擇的流程，不能宣稱與原版逐值一致。目前是 UI、日誌、任務與居民行為接入，尚無可見敵人或即時戰鬥。
