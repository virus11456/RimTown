# 同行目的地與可用時間

3D 同行提議現在先估算雙方到候選目的地的實際可行走路徑，包含建築出入口。沒有位置、端點不可行走或找不到連通路徑的候選不採用。使用較慢的每遊戲 tick 60 像素估算（實際標記赴約約 72 像素），另保留最多五 tick 出發倒數與兩 tick 緩衝。

從現在到預估抵達的每個 tick，都必須避開雙方的工時、通勤與睡眠；沿用 SimLeisurePlan 的同一作息判定，不另建不同規則。預估超出原到場期限也不採用。沒有候選時，不新增同行安排，但原交談正常進行。不提高好感、不增加提議機率、不延後睡眠、不追加物資，也不保證當下估算能預見後來的飢餓、避難或新行程。

實際位置觀察與 SimMotion 參考不存入世界；讀檔會清空兩者，待下一次場景觀察再評估。純世界無場景模式保留來源行為。速度調整同時推進時鐘與移動，不以更快遊戲速度增加旅程空檔。

135 項受控／回歸通過：可行性 8、提議產生 4、地點候選 6、共同到場 22、倒數 9、等待介面 5、自由交談／重播 33、休閒計畫 27、實際社交 8、玩家實際赴約 13。兩項舊提議測試明確改為 18:00 空閒時段；原 20:00 加上出發緩衝已接近睡眠，不應再要求一定能產生提議。

新測試用夜貓子 23:15 在公園的位置，確認附近公園保留、遠方圖書館排除；另驗證即使原地但空檔不足、工時、缺位置與斷路會拒絕，估算不改世界與居民位置。這些是受控檢查，獨立於自然長跑。
