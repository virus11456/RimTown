# 玩家邀約的返家時間與重新確認

玩家邀約的候選時間現在包含原有兩小時等候期限，再加上 NPC 從廣場慢走至自己住家的路程。回程會跨入睡眠、工作或通勤時段，或沒有有效回程，就改找較早時段；沒有空檔時不建立邀約、不消耗邀約冷卻。玩家仍需明確接受邀約卡。

接受時重新核對場所、作息與回程，防止尚未回覆期間條件已改變。玩家申請順延一天及 NPC 提出改約，都共用同一時段檢查；改約仍需玩家明確同意，且共用一次改期上限。回覆改約時若新時段又失效，取消並說明原因，不默默排入不適用行程。取消／改期文字已涵蓋工作、作息和返家衝突。

實際近距離見面完成後，NPC 使用前一包的有期限返家行程，沿道路與門口慢慢走回自己的住處。玩家不被自動帶回家，角色座標不搬動，既有緊急需求、工作與避難優先權維持。讀檔後會立即提供場景位置給行程檢查；缺少場景資訊時不猜測回程。

## 驗證

215 項檢查通過：新返家流程 16、原邀約核心 23、玩家順延核心 22、NPC 改約核心 23、完整邀約介面 14、順延介面 8、赴約引導 12、提醒介面 9、手機作息／存檔 13、自由聊天／重播 33、NPC 改約介面 10、同行回程 12、提早返家 20。

新核心涵蓋候選時間提前、接受時住家已失效、作息變更提出較早替代時間、同意時再次驗證、共用改期上限與存檔、無空檔拒絕且不消耗冷卻、缺少位置時不接受，以及實際碰面後只安排 NPC 回程。

UI 測試把陳偉設定為無職業的受控空閒日，因為原本的完整鎮長工時已放不下等候加回程，不能再假設所有晚間邀約都能成立。普通邀約改為 16:00，仍透過實際遊戲時間、NPC 路徑、玩家碰撞移動與近距離觀察完成；改約 UI 以較早睡眠偏好觸發新提議，驗證接受與拒絕、原生存檔和實際見面。沒有修改正式世界的職業或放寬時段限制。

玩家順延 UI 的自然進展在新日期因飢餓取消，並非成功碰面：作出決定前飢餓為 14.4，低於 15 門檻。測試保留這個有效取消，核對決定前的需求與顯示原因；同一 tick 隨後可能進食，不能用進食後需求否認先前的取消。普通邀約與 NPC 改約的實際碰面另有成功驗證。

本包未重跑自然多日邀約頻率或睡眠統計，不保證每位居民都能安排見面，也不保證當天沒有臨時需求。下一包進行自然多日驗收，觀察較嚴的返家限制是否令提議過少，以及已成立約定的抵達與回程結果。未呼叫正式 AI 服務；資源、移動速度與玩家操作不增加自動補償。
